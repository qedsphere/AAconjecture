This document merges the proof-pipeline log and the subsequent junta/DFKO investigations and corrections. It distinguishes \textbf{proved}, \textbf{conditional}, \textbf{numerical}, \textbf{open}, and \textbf{withdrawn/false} claims. It is not a list of accepted theorem claims: many initial submissions failed audit.

\subsubsection{Status notation}\label{status-notation}

\begin{itemize}
\tightlist
\item
  \textbf{{[}PROVED{]}} a theorem or lemma with a specific proof, either from a primary source or independently checked in this project.
\item
  \textbf{{[}PROJECT{]}} accepted in an earlier project log. The statement and its hypotheses should be retained, but the full proof was not independently re-derived in the latest audit pass.
\item
  \textbf{{[}CONDITIONAL{]}} a valid reduction only if the named unproved lemma is supplied. None of these closes the main problem.
\item
  \textbf{{[}NUMERICAL{]}} computational evidence only; not a proof.
\item
  \textbf{{[}OPEN{]}} no gap-free proof or counterexample currently exists.
\item
  \textbf{{[}FALSE/WITHDRAWN{]}} the statement or proof was found false/invalid and must not be reused.
\end{itemize}

The most important caution is that the recent \textbf{4 + 2 accepted submissions were narrow partial results}, not proofs of AA, the weak DFKO tail, or the simultaneous physical junta.
