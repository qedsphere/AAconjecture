\subsection{Provenance and scope}\label{proof:thin_shell_obstruction:provenance-and-scope}

Every counterexample formula above is an elementary deduction, with no
imported theorem or numerical premise. The parent agent proposed the
construction; this agent independently checked it, including correction
of the \(n=6\) covariance endpoint. No novelty claim is made.

Both laws are permutation invariant. The separate theorem in
Section~\ref{proof:exchangeable_queries}, using uniform-input AA, therefore
proves polynomial classical acceptance simulation for these same input
families. Thus these are explicit examples where full bit-flip influence
AA fails while the acceptance-simulation conclusion holds; the
distinction is stronger than simply lacking a query lower bound.
