\subsection{Covariance characterizes only degree
one}\label{proof:higher_order_obstructions:covariance-characterizes-only-degree-one}

Let \(\Sigma=\operatorname{Cov}_\mu(X)\). For a globally bounded
\(f = c+a\cdot x\), \(\lVert a\rVert_{1} \le  1\),
\(\operatorname{Var}(f) = a^{T}\Sigma a\), and \(I_{i} = a_{i}^{2}\).
Hence degree-one AA with exponent A is equivalent, up to constants, to
\(a^{\mathsf T}\Sigma a\le C\lVert a\rVert_\infty^{2/A}\) for all
\(\lVert a\rVert_{1} \le  1\). In particular
\(\lVert\Sigma\rVert_{\mathrm{op}}\le K\) gives
\(\operatorname{Var}(f) \le  K\lVert a\rVert_{2}^{2} \le  K\lVert a\rVert_\infty\),
and therefore \(\max  I_{i} \ge  \operatorname{Var}(f)^{2}/K^{2}\). The
following degree-two counterexample has \(\Sigma  = \operatorname{Id}\).
