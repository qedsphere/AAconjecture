\section{Physical structure, symmetry, and what temperature can control}
\label{proof:threshold_physics}

The target in this section is \emph{acceptance simulation}: for every
\(T\)-query quantum acceptance function \(Q\), approximate \(Q(X)\)
using \(\operatorname{poly}(T,1/\epsilon)\) classical coordinate queries
in mean absolute error under the input law. Markov's inequality converts
this to the usual additive-error, high-probability formulation. All
positive conclusions import uniform-input AA. Statements explicitly
called conjectures are not proved.
