\subsection{Scope and conclusion}\label{ht:scope-and-conclusion}

Together with the degree-one magnetization counterexample for each fixed \(\beta>1\) in Section~\ref{proof:curie_weiss}, HT5 gives an exact threshold for the full polynomial influence statement in this normalized, zero-field Curie--Weiss family: it holds for every \(\beta \in [0,1]\) and fails for every fixed \(\beta>1\).

This is a mathematical influence theorem. It does not itself establish a quantum/classical query separation above the threshold, nor a classical simulation theorem under arbitrary correlated input distributions.
