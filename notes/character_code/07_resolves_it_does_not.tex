\subsection{What this resolves and what it does not}\label{qm:what-this-resolves-and-what-it-does-not}

The theorem rigorously establishes that a fixed, explicitly normalized, full-support Gibbs family can have a sharp AA threshold, including a matching positive theorem, a critical-point classification, and an actual quantum/classical query separation. It is stronger than a counterexample based solely on small local influences.

The cost is the Hamiltonian: membership in a global character code is a nonlocal predicate, and the penalty is \(\Theta(n)\). The argument does not establish a query threshold for bounded-degree finite-range Ising models. The separate Curie--Weiss analysis addresses a natural pair-interaction model and should be read with its own stated scope.
